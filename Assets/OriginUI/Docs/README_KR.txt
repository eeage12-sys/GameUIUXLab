ORIGIN UI HUD V1.2

[설치]
1. 기존 Assets/OriginUI 폴더를 삭제합니다.
2. 이 압축의 OriginUI 폴더를 Assets 안에 넣습니다.
3. TMP Essentials가 없다면 Import TMP Essentials를 먼저 실행합니다.
4. Console의 빨간 컴파일 에러가 0인지 확인합니다.
5. Tools > Game UI > ORIGIN UI > 1. Build Complete HUD + Menus 실행
6. 기존 ORIGIN_UI가 있으면 Rebuild 선택

[씬 자동 규칙]
- Hub_Field_Lightweight_V2 : TIME/HUNT 숨김
- NGF_CompactDungeon : TIME/HUNT 자동 표시
- ORIGIN_UI는 Play 중 씬 전환 후에도 유지됩니다.
- 던전 진입 시 TIME 03:00 / HUNT 0/5 기본값으로 초기화됩니다.

[테스트]
F6 : HP 감소

F8 : HUNT +1
F9 : Toast 알림
F10: E 상호작용 표시/숨김
ESC: Pause 열기/닫기
